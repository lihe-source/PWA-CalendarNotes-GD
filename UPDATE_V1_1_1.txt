CalendarNotesPWA V1.1.1 更新說明

本次修改：
1. 新增行程時，「提醒」預設勾選「準時」。
2. 新增行程時，「開始時間」預設為使用者開啟新增行程視窗當下的日期與時間。
3. 「結束時間」預設自動設定為開始時間 + 1 小時。
4. 新增行程視窗內，在使用者尚未手動調整結束時間之前，修改開始時間會自動重新計算結束時間為 +1 小時。
5. 若使用者手動修改結束時間，之後不再強制覆寫，保留使用者自行設定的結束時間。

部署：
- 本次只有 GitHub Pages 前端更新，不需重新建立 D1、不需執行 schema.sql，也不需重新部署 Cloudflare Worker。
- 將 V1.1.1 ZIP 內檔案覆蓋 GitHub Pages repository 根目錄即可。
