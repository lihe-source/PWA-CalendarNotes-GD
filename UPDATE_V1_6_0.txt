CalendarNotesPWA V1.6.0 更新內容

1. 響應式裝置版面
- 手機 <=767px：底部導航、固定月曆工作區、觸控優先。
- 平板 768–1099px：寬版雙欄內容、置中導航。
- 桌機 >=1100px：左側常駐導航、月曆與當日事項左右並排、設定頁三欄。
- 使用 CSS viewport breakpoint 自動切換，不依 User-Agent，視窗縮放與橫直向切換皆會重新適配。

2. 新增 5 款卡通主題（總共 10 款）
- 薄荷汽水
- 檸檬奶油
- 珊瑚夕陽
- 焦糖可可
- 星空靛藍
原本 5 款黃綠草地、天空藍、蜜桃橘、薰衣草紫、莓果粉全部保留。
所有主題仍可搭配黑色/白色模式，並保存使用者選擇。

3. 部署
- 本次僅修改前端介面與版本快取。
- 不需重新執行 D1 migration/schema。
- 不需重新部署 Cloudflare Worker。
- 只需將 ZIP 內檔案覆蓋到 GitHub Pages repository 根目錄。
