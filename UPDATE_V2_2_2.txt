V2.2.2 純 PWA 版（不含 EXE）

以使用者提供的 V2.2.1 為基礎，不使用 Electron 或桌面橋接。
1. 每次啟動、從其他頁切回行事曆時，依工作區時區選取今天並顯示當月。
2. 同一次瀏覽仍可手動選其他日期。跨日後回到前景重新選今天。
3. 行程列表獨立捲動，月曆與日期標題固定。
4. 備註列表獨立捲動，備註標題、搜尋及篩選列固定。
5. 小螢幕橫向採月曆／行程左右排列，避免整頁捲動。
6. 回到最上方按鈕跟隨目前列表操作。
7. 保留原 PWA 的啟動更新檢查、設定頁版本與檢查更新、資料同步及 Google 設定。

部署：將本資料夾內檔案覆蓋 GitHub 原本 PWA 所在位置，不要額外放入版本子資料夾。
本次不需重新部署 Cloudflare，也不需安裝 Node.js 或任何桌面程式。
GitHub Pages 發布後重開 PWA，或在設定頁按檢查更新；確認版本為 V2.2.2。
請保留原 PWA 安裝與本機資料，不必解除安裝或清除瀏覽器資料。
